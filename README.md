
# Master's Degree in Applied Artificial Intelligence

🌐 **English** | [Español](./README_ES.md)

Its purpose is to document my learning journey and demonstrate the practical application of artificial intelligence techniques, data analysis, and Python programming.

- **Development environment:** Jupyter Notebooks and Python scripts
- **Version control:** Git and GitHub

## Repository Structure

Each folder corresponds to a subject from the Master's program and contains programming exercises and solutions developed throughout the course.

The projects are mainly provided in two formats:

- **`.py`:** Python scripts and programming exercises.
- **`.ipynb`:** Jupyter Notebooks containing code, explanations, and execution results.
