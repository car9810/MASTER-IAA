
# Máster en Inteligencia Artificial Aplicada

Este repositorio reúne las prácticas y ejercicios de programación desarrollados durante mi formación en el Máster en Inteligencia Artificial Aplicada del Instituto Europeo de Posgrado (IEP).

El objetivo es documentar mi aprendizaje y mostrar la aplicación práctica de diferentes técnicas de inteligencia artificial, análisis de datos y programación en Python.

## Tecnologías y herramientas

- **Lenguaje principal:** Python
- **Entorno de trabajo:** Jupyter Notebooks, VSC y archivos Python
- **Control de versiones:** Git y GitHub
- **Bibliotecas y frameworks:** Pendiente de completar

## Contenido del repositorio

El repositorio está organizado en diez áreas de aprendizaje:

| Asignatura | Área de estudio |
|---|---|
| [AI Platforms](./AI%20PLATFORMS/) | Plataformas e infraestructura para soluciones de inteligencia artificial |
| [Computer Vision](./COMPUTER%20VISION/) | Visión por computador y procesamiento de imágenes |
| [Data Science](./DATA%20SCIENCE/) | Análisis, tratamiento y exploración de datos |
| [Deep Learning](./DEEP%20LEARNING/) | Redes neuronales y aprendizaje profundo |
| [Generative AI](./GENERATIVE%20AI/) | Inteligencia artificial generativa |
| [Machine Learning](./MACHINE%20LEARNING/) | Algoritmos y modelos de aprendizaje automático |
| [NLP](./NLP/) | Procesamiento del lenguaje natural |
| [Python](./PYTHON/) | Fundamentos y programación en Python |
| [Recommendation Systems](./RECOMMENDATIONS%20SYSTEMS/) | Sistemas de recomendación |
| [Time Series](./TIME%20SERIES/) | Análisis y modelado de series temporales |

## Organización de las prácticas

Cada carpeta corresponde a una asignatura del máster y contiene ejercicios y soluciones desarrollados durante la formación.

Los trabajos se presentan principalmente en dos formatos:

- **`.py`:** scripts y ejercicios de programación en Python.
- **`.ipynb`:** cuadernos Jupyter que permiten consultar el código, las explicaciones y los resultados de su ejecución.

## Objetivo profesional

Este repositorio forma parte de mi portfolio técnico y refleja mi formación práctica en distintas áreas de la inteligencia artificial.

Su finalidad es mostrar mi evolución en programación, resolución de problemas y aplicación de técnicas de IA, así como facilitar la consulta de los ejercicios realizados.
